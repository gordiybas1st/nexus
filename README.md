# Nexus

Android-приложение: даёте ссылку на грант/конкурс/задание, Gemini достаёт название, дедлайн и шаги,
приложение напоминает за 7, 3 и 1 день и в день дедлайна. Всё хранится на телефоне.

## Установка APK
1. Залить проект на GitHub (ветка `main`), открыть вкладку **Actions** → **Build APK** → дождаться зелёной галочки.
2. В запуске внизу, в разделе **Artifacts**, скачать `nexus-apk`, распаковать, отправить `app-debug.apk` на телефон и установить
   (разрешить установку из неизвестных источников).
3. В приложении открыть настройки и вставить свой бесплатный ключ с https://aistudio.google.com/apikey.

## Использование
Вставьте ссылку или нажмите «Поделиться» в браузере → Nexus.

## Разработка
```
cd app
npm install
npm run dev
```

`legacy` Python-прототип: `Nexus_Logic.py`, `check_models.py` (нужна переменная `GOOGLE_API_KEY`).
